# 臺灣數學教材設計與排版

## 定位與邊界

可從教材設計、數學圖文、排版輸出的任一模式開始，也可連續執行。整份段考涉及雙向細目表、配分與正式命題時，由試卷工作流程主責，本技能提供數學素材與排版。

## 開始前

讀取現有題目、教師指定範圍、目標格式及工作區已有的 `teacher-profile.md`。若既有套組提供共用 workflow，依照該工作方式交接。以本次明示要求為準。若老師指定校版字型，記入輸出規格。考卷依題長和作答空間選單欄、雙欄或按題組混排。若教師指定左右欄題區，在右欄首題設定換欄。只在年級、先備或題目條件會改變成果且無法推知時詢問。既有教材的修訂先分清楚補圖、排版與內容改寫。

## 思維路線

1. 從單元與目標開始 → 讀 [教材設計](references/design.md)，把目標轉成學生任務和可觀察的作答證據。
2. 只需圖表或公式 → 讀 [數學圖文](references/math.md)，求出必要座標、數值和標記，再繪圖或排式。
3. 已有題目要排版，或內容準備完畢 → 讀 [排版輸出](references/output.md)，以同一來源產生學生版與所需教師版。
4. 發現題意歧義、圖文矛盾或欠缺數據 → 就地標記並列出待確認項；其餘可驗證內容先完成。

## 台灣情境要點

使用繁體中文與教師指定記法。課綱對照依實際學段及高中課程類別回查。入口、轉化案例和證據界線見 [教材設計](references/design.md)。

## 產出

依 [教材資料格式](references/output.md) 交付可重製的資料、數學來源與所需文件。內附 Python 產生器以結構化公式輸出 Word 原生 OMML。三份原創案例可用於重跑。可只交付圖形與來源，或輸出完整 A4 文件。

## 品質關卡

驗算參數、數據與解答。檢查角弧、刻度、軸單位、數學符號、圖題配對與作答空間。開啟實際 DOCX 和 PDF，核對指定與實際使用的字型、內嵌狀態、換行、黑白可辨與公式編輯。獨立算式若要求算出結果，確認已有等號及填答空位。題內行距、題間距與手寫留白分別檢查。雙欄檢查題序、欄寬、題圖及作答線，長題或寬表格優先安排全寬。掃描學生版正文、替代文字及隨附檔案，確保答案留在教師版。將未能驗證的格式或內容列進交付說明。

## 交接

以題目 ID 對應學生題幹、圖文來源和教師答案。交給學習單、試卷、簡報或教材審查流程時，一併提供來源、可編輯範圍及待確認事項。現有通用文件技能的輸入介面仍需依各自 schema 轉接。
