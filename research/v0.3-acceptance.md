# v0.3.0 版面與自動選用設定

2026-11-22 以正式產生器重跑 16 組，含 32 份 Word 與 32 份 A4 PDF。三學段教材、三工作模式、三種考卷版面與固定左右欄皆有案例。核對 Word 三個標題層級，固定雙欄樣卷雙版本各一頁，子題依序為（1）（2）（3）。學生卷沒有教師解析，作答區無描線，需計算結果的公式保有末尾等號。舊資料可使用原來的題目 ID 及 answer_lines，後者轉為同等用途的空白高度。

自動選用的描述涵蓋臺灣數學教材、數學程式與統計圖表。Codex 設定允許隱式選用。以下可在支援自動選用的宿主用新對話驗收，每條使用原始請求，不預先指名技能：

| 請求 | 預期模式 |
|---|---|
| 做一張五年級分數乘法學習單，有學生卷與答案。 | 教材設計、排版 |
| 把現有幾何題排成左右欄 PDF。 | 排版，視需要補數學圖文 |
| 用 JavaScript 畫 0 到 2π 的 sin 和 cos，標出零點。 | 數學圖文，交付程式與驗證 |
| 寫矩陣相乘函式，維度不相容要報錯。 | 數學圖文與程式驗證 |
| 把 CSV 畫成不等組距直方圖，柱面積代表頻數。 | 數學圖文，核對頻率密度 |
| 修正登入表單或設計營運總覽頁。 | 由一般開發或儀表板流程處理 |

驗收範圍涵蓋實際文件輸出、技能結構與設定，未量測宿主自動選用命中率。
