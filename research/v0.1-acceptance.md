# v0.1.0 驗收紀錄

執行日期 2026-11-22。使用三套原創教材，經 Python、python-docx 與 LibreOffice 產生學生及教師版，共 6 份 DOCX、6 份 A4 PDF。PDF 共 8 頁，逐頁渲染檢視。匯出器起初漏讀使用者字型，改用可找到 Noto Sans TC 的字型目錄後，已重新匯出並確認繁中可見。

| 案例 | 已檢查的結果 |
|---|---|
| 國小 E1–E2 | 射線座標反算為 35°、115°，角弧方向符合起始邊。數線等距，第三刻度相對位置為 0.75。 |
| 國中 J1–J2 | 外高作答圖保留延長空間，教師解答的垂足為圖面 (120,125)。分組次數重算為 2、3、3，共 8 筆。 |
| 高中 H1–H2 | AB 與 BA 重算後不相等。AC 維度不相容，CA 為 3×2。聯立解 (3,1) 代回兩式成立，x 軸投影為 (3,0)。 |
| 高中 H3–H4 | 驗算 sin(120°)=√3/2、cos(120°)=−1/2。核對兩曲線的關鍵點、線型、週期與弧度標示，倒數函數橫跨零點時採分段繪製。 |
| 學生與教師版 | 檢查學生 JSON、DOCX 內部 XML 和 PDF 文字，學生檔沒有解答標記，教師 PDF 有解答。學生圖形替代文字保留作答所需條件。 |
| 公式與版面 | 驗證 OMML 矩陣、聯立、分數結構。修改測試副本的矩陣元素與三角公式後儲存重開，結構仍在。八頁渲染確認題圖與文字可辨。 |

Skill frontmatter 通過 `skill-creator` 的 `quick_validate.py`。公式修改重開是透過文件結構檢驗。Microsoft Word 桌面互動操作、實體紙本及教師試教尚待驗收。

## 路由驗收例

| 教師請求 | 應讀取的模式與交付 |
|---|---|
| 「做一份四年級學生能實際量角的練習」 | 教材設計、數學圖文、排版輸出。學生版有量角空間，教師版有解答和追問。 |
| 「畫 115° 的角，讓我改角度再生成」 | 數學圖文。提供 SVG 與座標、角度參數。 |
| 「內容已審過，把這份題目排成 Word 和 PDF」 | 排版輸出。保留題意，核對公式、題圖及分頁。 |
| 「照雙向細目表出整份段考」 | 試卷技能主責，圖文部分可交接本技能。 |
